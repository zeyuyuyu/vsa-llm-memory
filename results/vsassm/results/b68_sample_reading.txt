1. Qwen3-8B input embeddings, arena A, dkvb (965 right, 35 wrong of 1,000). In all six right instances every chain
   mention (query role, context role, X value / key, Y value / key, filler, candidate) got the same key as the other
   mention of its written form, and different forms got different keys; one right instance carried an anagram pair
   ([Y40] / [Y04]) that shared a key without being needed. All six wrong instances are anagram collisions inside the
   instance: [R23] / [R32], [R10] / [R01], [X21] / [X12], [YF6] / [Y6F], [R30] / [R03], [R21] / [R12] share one key
   because Qwen3-8B writes each hex digit as its own token, so the span mean of the input embeddings is the same for
   both orders. Five of the six fail at hop 1 or hop 2 (the wrong partner's value is retrieved); one ([YF6] / [Y6F]) is a
   false 'yes' because the two Y symbols' values are superposed. No failure comes from inconsistent codes.
2. Phi-2 input embeddings, arena A, dkvb (995 right, 5 wrong). The five errors are again anagram pairs sharing a key
   ([YF6] / [Y6F], [X3F] / [XF3], [X5B] / [XB5], [XD6] / [X6D], [XA0] / [X0A]): Phi-2 splits these markers into the same
   token multiset. The right instances look like item 1.
3. So at L0 the label-free reader is a hash of the written token multiset: its accuracy equals the feature hash
   (Qwen3-8B 0.972 vs 0.975, Phi-2 0.996 vs 0.995) and its errors are the hash's collisions. The memory did not have to
   learn anything: dkvb's keys are frozen k-means centres of the frozen states, its dev-selected epochs are 1-3, and its
   accuracy at the final epoch is the same.
4. Qwen3-8B layer 2, arena A, vq (786 right, 214 wrong). Two failure kinds in the four wrong instances read: (a) the query
   role in the question line and the same role in the context get different codes ([R0A] codes 24 / 63; [R0C] 24 / 25):
   the state of a mention already depends on its surroundings after two blocks, the failure B48 found at the final
   layer; (b) forms one digit apart share a code ([R06] with [R16] and [R26]; [R19] / [R17]; [R1E] / [R3E]): k-means on
   the layer-2 states merges neighbouring written forms. Neither needs labels to explain; both are geometry of the
   contextual state.
5. Nothing read here contradicts the verdict's numbers; no number was changed.
