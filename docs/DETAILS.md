# Details

The full map from the paper to the files, the source repositories, and per-experiment rerunning notes. Start with the [README](../README.md).

The package was assembled on 2026-11-28 from four source repositories and two directories of curated files. `docs/PROVENANCE.tsv` records, for every file, its source path, git state, last commit and SHA-256 before and after packaging; `docs/BUILD_INFO.json` records the build.

merged: `python3 tools/assemble_tree.py` writes `work/<source>/` with the packager's gzipped files expanded back to
their original names. Run the scripts from `work/<source>/`.

## Claim map

One row per figure, table and group of numbers. The rows for the current manuscript, its Supplementary Information
and the Supplementary Record come first. The rows marked [2026-11-18 version] were written for the earlier version
of the manuscript and name its sections: those analyses are now in Part II of the Supplementary Information or in
the Supplementary Record, except the operational-log experiments (B15, B16, NSR1-NSR5), which the current manuscript
assigns to another study and does not report; their files are kept for traceability. Paths are relative to the repository root; a `.gz`
suffix marks a file that the packager compressed. The figure data layer (`figures/figdata/`) carries a pointer from
each plotted or quoted value to its source file, and for transcribed values the verbatim source line;
`figures/check_sources.py` re-checks all of them against this package. For the controlled experiments,
`figures/figdata/INDEX.json` maps each value to its run artifact and the expression that reads it.

## Rerunning

Environment: Python 3.10 and `requirements.txt`. The GPU experiments download their models from the Hugging Face Hub
(Qwen3-1.7B, Qwen3-8B, Qwen3-32B, Qwen2.5-7B-Instruct, Qwen2.5-32B-Instruct, `microsoft/phi-2`,
Granite-3.3-8B-Instruct, Llama-3.1-8B-Instruct, Mistral-7B-Instruct-v0.3, and the sentence encoders e5-base-v2,
bge-small-en-v1.5 and all-MiniLM-L6-v2); no weights are included. Large regenerable intermediates (the encoders'
code matrices, fitted FAISS and product-quantization caches, pickled check matrices) are not packaged; `WITHHELD.md`
and the experiment notes below give the command that regenerates each and the MD5 to check it against. Frontier-model arms need API keys, which the scripts read from files in the user's home directory (the
file names are in the scripts; no key is included). Paths of the authors' machines are replaced by placeholders
(`/path/to/vsassm`, `/path/to/pace-scratch`, ...); set them to your checkout. Every verdict generator and scorer runs
on CPU from the saved outputs.

Hardware used:

- Controlled arenas and bAbI: one NVIDIA H20 (96 GB) (Methods).
