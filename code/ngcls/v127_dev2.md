
## 2026-09-10 — V-127 DEVIATION #2: my first repair was the WRONG DIAGNOSIS. The paragraph arm's failures are TRUNCATED JSON caused by my own 200-token output ceiling, not transient errors — and that is why raising retries made it worse.

**Evidence.** Re-run under deviation #1 (retries 4->8, backoff 4s) scored **291/300**, *worse* than the
original 299/300. Every one of the 9 failures is truncated JSON:

```

```

**Mechanism, and it is my bug.** `max_tokens: 200` in the harness. `deepseek-v4-flash` spends output
budget on reasoning tokens that **CommonStack does not return** (no `reasoning` field — recorded in the
prereg as deviation 3), so the budget is consumed invisibly and the visible JSON is clipped. The longer
PARAGRAPH contexts induce more of it, which is exactly why paragraph fails (9/300, and 1/300 in run 1)
while SENTENCE never does (0/300 in both runs). Retries cannot fix a systematic ceiling — each attempt
truncates at the same place — so run 2 was resampling noise around it, and landing worse was luck.

**This is the same phenomenon the ICLR draft reports in Sec 4.2**, one step further: an unreturned
reasoning trace does not only make hop attribution uninterpretable, it silently consumes the answer
budget on the gateway that hides it. Worth a sentence in the paper.

bars, the judge template, the row set and its shas, the 40-row calibration (0e39292) and the frozen
